\section{Derivative-Free Optimization}

%-------------------------------------------------------------------------
\begin{frame}
  Let~$\domain\subset\Rn$ and~$\func:\domain\to\R$. 
  We want to minimize the function~$\func$
  \begin{align} \label{eq: opti}
    \min_{\var\in\domain} \quad & \func(\var)
  \end{align}
  If~$\func$ is smooth (i.e., continuously differentiable) then to solve~\eqref{eq: opti}, we can use gradient desecent methods, such as steepest descent method or Newton-like methods, which can generally generate the solution by updating at each iterate
  \begin{align*}
    \var_{n+1}=\var_{n}-\step\grad\func(\var_{n})
  \end{align*}
\end{frame}
%-------------------------------------------------------------------------


%-------------------------------------------------------------------------
\begin{frame}
  We are here to answer three questions:
  \begin{enumerate}
    \item What information does a gradient use that a population-based methods does not have directly?
      
      \red{An} Gradient methods use the first-order derivative of the objective function.
      The gradient provides the descent direction in the search process to obtain the minimizer which the population-based methods do not access.
      Derivative-free methods evaluate the objective function values at the a set of candidate points and select the best that improves the function value.
      These methods however, help us to do optimization with nonsmooth functions which is practical in real-world applications.

    \item Why can derivative-free methods still recover perferred directions of descent?

      \red{An} Yes, DFO can recover the descent direction even without gradient information.

    \item What difficulties arise when $\dimension$ is large?
  \end{enumerate}
\end{frame}
